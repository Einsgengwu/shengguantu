# 大宋升官图 · 升官竞速棋

"朝为田舍郎，暮登天子堂" —— 掷骰行棋，自从九品竞登正一品·太师，先至者胜。

🎮 **[在线游玩](https://einsgengwu.github.io/shengguantu/)**

## 玩法简介

- 1–4 人对局（支持 AI 托管）或 2v2 组队
- 掷骰子沿三环回字盘前进，历经北宋官制各品阶
- 事件格：升迁、贬谪、奇遇、谋反……宦海浮沉，升黜无常
- 道具系统：弹劾令（降对手品阶）、禁足令（停掷一回合）、商肆购买
- 最先抵达正一品·太师者，位极人臣，对局即胜

## 文化背景

升官图是中国古代传统博戏，起源于唐代"彩选格"，明清时定型为春节合家围坐的年俗游戏。本作取其"掷骰竞官"之核心，以北宋官制重新演绎，配以水墨国风视觉。

## 技术栈

- 纯 HTML / CSS / JavaScript，无需构建工具
- 水墨国风 UI，宣纸纹理背景
- 响应式设计，支持桌面和移动端

## 本地运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

# 大宋升官图 · 升官竞速棋

“朝为田舍郎，暮登天子堂” —— 掷骰行棋，自从九品竞登正一品·太师，先至者胜。

🎮 **[网页试玩](https://einsgengwu.github.io/shengguantu/)**

## 玩法简介

- 1–4 人本地对局，支持 AI 托管和多人轮流操作
- 支持自由对战与 2v2 组队模式
- 掷骰子沿三环回字盘前进，历经北宋官制各品阶
- 事件格包含升迁、贬谪、奇遇、谋反与多种抉择
- 可使用弹劾令、禁足令、定数骰和护身符，也可进入商肆购买道具或捐纳买官
- 最先抵达正一品·太师者位极人臣，对局即胜；组队模式下一人登顶，全队获胜

## 版本说明

本仓库为独立单机版本，保留原有水墨界面、自由对战、2v2、AI、游戏引导、道具、背景音乐与音效。房间大厅、邀请链接、网络同步和联机对战功能已移除。

项目不使用 WebSocket、后端接口或数据库，可直接部署到 GitHub Pages 等静态托管平台。

## 文化背景

升官图是中国古代传统博戏，起源于唐代“彩选格”，明清时定型为春节合家围坐的年俗游戏。本作取其“掷骰竞官”之核心，以北宋官制重新演绎，配以水墨国风视觉。

## 技术栈

- 纯 HTML / CSS / JavaScript，无需构建工具
- 水墨国风 UI、宣纸纹理与响应式棋盘
- 支持桌面端和移动端浏览器
- 音乐、背景图和游戏资源均随仓库提供

## 本地运行

在项目目录启动任意静态服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`。项目也可以直接发布到 GitHub Pages，入口文件为根目录的 `index.html`。

大宋升官图 · 玩法规则

"朝为田舍郎，暮登天子堂"——掷骰行棋，自从九品竞登正一品·太师，先至者胜。

简简单版

每位玩家以从九品小官起步，轮流掷骰前进，落到事件格就按提示升官、降官、得钱或受罚，遇到选择格就选一条路。途中可以攒钱、买道具、捐纳买官，也要提防弹劾、禁足和谋反风险。谁先走到终点成为正一品·太师，谁就获胜；组队模式则一人登顶，全队同胜。

一目标

众人皆自起点 从九品·太常寺奉礼郎 出发，沿三环回字盘竞速。最先抵达终点正一品·太师者，位极人臣，对局即胜。（本游戏选本官作为游戏官阶）

二行棋

轮流掷一枚骰子（1–6 点），按点数沿盘面前进。落于何格，即结算该格事件。点击任意格子可预览其内容与效果。
为求平衡，同一人连掷三次同一点数后，下一次掷骰不再生成该点（定数骰指定者除外）。

三格子

官职格锚定品阶（绿/绯/紫三章服）；事件格有进 N / 退 N / 升 N 阶 / 降 N 阶 / 困住 / 原位驻留 / 低阶贪墨进财等；奇遇格（金）天降际遇；多处抉择格如叙事——每格 3–4 项抉择，选项只述意态、不剧透结果，择而后知，一念之间或进或退、或升或贬、或得财得械，结局各异；谋反格投骰定数（单数回起点赠弹劾令 ×2，双数降 3 阶且困 1 回合）；高位谋反篡位格投骰：6 直接称帝获胜、4 退 4 阶且困 1 回合、余点贬回起点。

四品阶

当前官职由所在或其后最近的官职格推导。"升 N 阶"＝跳至前方第 N 个官职格，"降 N 阶"反之。单回合连升至多 3 阶。

五道具

弹劾令：掷骰前用，使一名对手降一品阶（对正二品及以上者无效）。禁足令：使一名对手下一回合不得掷骰。每人同时最多持有 3 件，对队友无效。
护身符：被对手弹劾或禁足时弹窗询问，可选择消耗一枚以免除该令。商肆可购（620 缗，购买不限、同时最多持有 2 枚，独立计），盘上与奇遇亦可得。
定数骰：掷骰前用，指定下一掷必得之点数。商肆可购（520 缗，购买不限、同时最多持有 2 枚，独立计），盘上亦有两格可拾得。

六钱财·商肆

每次升官获钱财（品阶越高越多），降官则相应扣减、下限为零。掷骰前可入商肆购弹劾令（450 缗）/ 禁足令（600 缗）/ 定数骰（520 缗） / 护身符（620 缗），单局购买皆不设上限，唯受持有约束：弹劾令、禁足令共占一栏、同时不过 3 件；定数骰、护身符另计、各同时持有不过 2 枚；亦可捐纳买官——从八品 / 从七品上 / 从六品上 / 从五品上 / 从四品五等，不同价、直升其阶。盘上散布三处贪墨进财格，越高位赃银越丰。

七连锁与上限

因进退而落入新事件格会连锁触发（至多 2 次）。降职以从九品为底、连升以 3 阶为顶，盘势不致失衡。

八对战模式

自由对战：1–4 人，余席可 AI 托管。2v2 组队：甲乙两队交错行棋，同队同色仅棋子字不同；任一队员登顶全队同胜。

文

升官图 · 千年源流

一枚博具，半部官制——升官图以游戏摹写宦海浮沉，自唐迄今，雅俗共赏。

唐 · 源

彩选格 · 博戏滥觞

升官图的远祖，是唐代盛行的「彩选格」（又称选官图、彩选）。"彩"即掷具所得之采（点数），玩者依采在图上选格升黜，故名"彩选"。李肇《唐国史补》已记"骰子选"之戏；其图自卑秩起，循采递迁，初具"以游戏摹官阶"的雏形。（创制者后世多有附会，姑且存疑。）

宋元 · 流

士林雅玩 · 寓劝于戏

两宋承唐余绪，彩选之戏流行于士大夫间，常见于宴集清谈。文人嫌其专取富贵荣华、逐利忘德，遂有改制之议——主张重德行、抑贪墨，使升黜系于品节而非侥幸，"寓劝惩于博弈"。元代承之，规制渐繁。

明 · 定

升官图定型 · 德才功赃

至明代，此戏定名「升官图」（亦称百官图、选官图），体例大成。掷具多用一枚四面之"琼"或捻转之陀螺，四面刻 德 · 才 · 功 与 赃：得德才功则擢升，遇"赃"则贬黜、罚俸乃至削籍。棋盘自白丁经科举（秀才—举人—进士—状元）入仕，历部院台谏、地方藩臬，直抵三公太师，封爵荫子。明末士人亦多以之自况官场炎凉。

清 · 盛

合家博戏 · 年节之欢

有清一代，升官图臻于鼎盛，由士人雅玩走入寻常巷陌，成为春节、元宵合家围坐的博戏。坊间刊印图样、配以四面"升官桶"骰，老幼皆可对局；孩童于嬉戏间熟习官制品级，长者借升黜无常笑谈宦海，可谓寓教、娱乐、讽喻三得。

今 · 韵

民俗遗韵 · 古戏新声

科举既废、官制更易，升官图退为民俗文化遗存，却以其"掷骰竞官、升黜无常"的巧思与谐趣，长存于年画、收藏与桌游之中，被视作中国古代讽喻性桌游的代表。

本作 · 承

《大宋升官图》· 旧戏新裁

本作取升官图"掷骰竞官"之核心与"升黜无常"之讽喻精神，落点北宋官制（寄禄官阶），自从九品·太常寺奉礼郎竞登正一品·太师；并重制为三环回字盘，增益事件、奇遇、谋反与弹劾令 / 禁足令 / 商肆钱财诸般机巧，使千年古戏，复见水墨新颜。

参酌：唐·李肇《唐国史补》"骰子选"；历代升官图（彩选格）民俗博戏流变。文中创制人物与年代细节，民间记载互见，部分姑从其略。
